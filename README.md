## 🩸 À propos / About

**Codex Satanas** est un thème Discord intégralement conçu dans les tons noir abyssal et rouge sang artériel (`#ff172b`, `#cc0a1d`, `#3d050b`), bannissant tout le gris et les teintes ternes de l'interface par défaut de Discord. 

Contrairement aux thèmes générés par IA, **Codex Satanas** s'appuie sur de véritables **gravures occultes et satanistes historiques** du XVIᵉ et XIXᵉ siècle numérisées et restaurées en encre de sang :
- **Le Sceau de Baphomet** (*Stanislas de Guaita, La Clef de la Magie Noire, 1897*) avec les inscriptions hébraïques d'origine (`לויתן` - Léviathan).
- **Le Bouc de Mendès** (*Éliphas Lévi, Dogme et Rituel de la Haute Magie, 1856*) arborant `SOLVE` et `COAGULA`.
- **Le Sceau Complet de Lucifer** (*Grimorium Verum, 1517*).

- 🩸 **100% Rouge Sang & Noir Abyssal** : Remplacement exhaustif de toutes les variables de couleur Discord (y compris la refonte visuelle 2026, les icônes, les bordures et les survols).
- ⸸ **Croix de Saint-Pierre (`⸸`) & Croix de Léviathan Animées** : Couronne rituelle en orbite continue et pulsations lumineuses occultes.
- 🧪 **Coulures de Sang Réalistes 3D** : Effets de liquide organique et de brillance spectrale (filtres SVG `feTurbulence` + `feSpecularLighting`).
- 🎙️ **Salons Vocaux & Partage d'Écran Redessinés** : Cartes des participants en verre cramoisi avec filigrane de Baphomet, halos de prise de parole incandescents, et boutons de stream arrondis.
- 🎛️ **Boutons & Contrôles Verre d'Obsidienne** : Redesign ergonomique des boutons de fenêtre (Réduire / Agrandir / Fermer), de la barre de son (*soundboard*), du partage d'écran et des sélecteurs de micro.
- 🎵 **Lecteur Spotify & Vencord Intégrés** : Barre de progression liquide rouge vif, badge d'écoute et contrôles coordonnés.
- 🖋️ **Typographie Gothique & Antique** : Intégration des polices *Cinzel Decorative*, *UnifrakturMaguntia*, *Cormorant Garamond* et *JetBrains Mono*.

**Codex Satanas** a été conçu selon les standards ouverts CSS Discord. Il est compatible avec la quasi-totalité des clients personnalisés et injecteurs CSS :

| Client Discord | Compatibilité | Méthode d'installation recommandée |
| :--- | :---: | :--- |
| **Vencord** (Desktop) | ✅ **100% Natif** | Thème en ligne (*Online Theme*) ou fichier local |
| **Vesktop** (Linux / Win / Mac) | ✅ **100% Natif** | Thème en ligne (*Online Theme*) ou fichier local |
| **BetterDiscord** | ✅ **100% Natif** | Dossier de thèmes (`.theme.css`) |

### 🔍 Comment savoir si mon client est compatible ?
Si votre client Discord dispose d'une de ces fonctionnalités :
1. Un onglet **Themes** acceptant les URLs brutes (*Online Themes / Remote CSS*),
2. Un dossier local de thèmes (reconnaissant les fichiers se terminant par `.theme.css`),
3. Un champ de texte **QuickCSS / Custom CSS** pour coller du code,

👉 **Alors Codex Satanas fonctionnera parfaitement.**

## 📥 Installation

### Méthode 1 : Vencord / Vesktop (Installation en 1 clic — Recommandée)

1. Ouvrez Discord.
2. Allez dans les **Paramètres utilisateur** (⚙️) > **Vencord** (ou **Vesktop**) > **Thèmes** (*Themes*).
3. Dans la section **Thèmes en ligne** (*Online Themes*), collez le lien direct suivant :
   ```text
   https://raw.githubusercontent.com/deadcow-ghw/Codex-Satanas/master/codex-satanas.theme.css
   ```
4. Cliquez sur **Entrée** ou activez l'interrupteur. Le thème s'applique instantanément !

---

### Méthode 2 : BetterDiscord / Vencord (Fichier local)

1. Téléchargez le fichier [`codex-satanas.theme.css`](https://raw.githubusercontent.com/deadcow-ghw/Codex-Satanas/master/codex-satanas.theme.css).
2. Ouvrez Discord > **Paramètres utilisateur** (⚙️) > **Thèmes** (sous *BetterDiscord* ou *Vencord*).
3. Cliquez sur **Ouvrir le dossier des thèmes** (*Open Themes Folder*).
4. Déplacez le fichier `codex-satanas.theme.css` dans ce dossier :
   - **Linux** : `~/.config/BetterDiscord/themes/` ou `~/.config/Vencord/themes/`
   - **Windows** : `%appdata%/BetterDiscord/themes/` ou `%appdata%/Vencord/themes/`
   - **macOS** : `~/Library/Application Support/BetterDiscord/themes/`
5. Activez l'interrupteur **Codex Satanas** dans Discord.

---

### Méthode 3 : Discord Web (via extension Stylus)

1. Installez l'extension [Stylus](https://add0n.com/stylus.html) sur votre navigateur (Chrome, Firefox, Brave, Edge).
2. Cliquez sur l'icône de Stylus > **Écrire un nouveau style** pour `discord.com`.
3. Copiez l'intégralité du contenu de [`codex-satanas.theme.css`](codex-satanas.theme.css) et collez-le.
4. Enregistrez : Discord Web bascule instantanément dans l'abysse de sang.

## 🛠️ Personnalisation & Variables CSS

Vous pouvez ajuster les nuances de sang en modifiant les variables `:root` :

```css
:root {
  --crimson-bright: #ff172b;  /* Rouge sang artériel éclatant */
  --crimson-wet:    #cc0a1d;  /* Sang frais liquide */
  --crimson-artery: #960816;  /* Sang artériel intermédiaire */
  --crimson-clot:   #3d050b;  /* Sang coagulé sombre */
  --crimson-abyss:  #0d0102;  /* Noir abyssal de fond */
}
```
